# buildlog

Things I've built and shipped.

## Adding a project

Open `projects.json`, copy one entry, and fill in:

- `title`: one line describing what the project does
- `url`: link to the repo
- `stack`: the main tools, as a list
- `highlight`: one short result or key detail
- `demo`: link to a live demo, or leave it as `""`

Projects appear in the same order as in the file, and the numbering is automatic. Save the change and the site updates on its own.
